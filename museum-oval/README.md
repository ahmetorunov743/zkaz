# NXT Fit Out Technical Service: овальная 3D-галерея (демо v0.1)

Сайт в виде музея с овальным коридором-кольцом: посетитель скроллит и идёт по кругу, коридор никогда не заканчивается.
На обеих стенах висят проекты как картины. Раз в круг проходишь через входную арку с информацией о компании,
а перед ней висит стена с призывом связаться и телефоном.
Клик или тап по картине: камера подлетает к ней, рядом выезжает панель с информацией.

Чистые HTML + CSS + JS и Three.js r128. Без сборки и без сервера: открой `index.html` двойным кликом.

## Файлы
```
index.html     разметка: загрузочный экран, шапка, панель проекта, подвал
styles.css     все стили (цвета и размеры в :root)
script.js      3D-сцена, камера, клики, перевод
i18n.js        настройки (год, телефон, WhatsApp, версия) и ВСЕ тексты EN / RU / AR
projects.js    проекты (массив объектов)
privacy.html, terms.html   документы-заглушки
assets/logo    логотип: nxt-logo-black.svg, nxt-logo-white.svg
assets/images  сюда кладутся фото проектов
vendor/        локальная копия Three.js на случай, если CDN недоступен
```

## Как добавить проект
1. Положи фото в `assets/images/`.
2. Допиши объект в `projects.js`:
```js
{
  id: 31,
  title: { en: "Villa Azure", ru: "Вилла Azure", ar: "فيلا أزور" },   // или просто "Villa Azure"
  location: { en: "Palm Jumeirah", ru: "Пальм-Джумейра", ar: "نخلة جميرا" },
  workType: "marble",          // fitout | renovation | marble | tile | parquet | metal | glass
  year: 2025,
  area: 640,                   // м²
  description: { en: "...", ru: "...", ar: "..." },
  images: ["assets/images/azure-1.jpg", "assets/images/azure-2.jpg"]   // первое фото висит на стене
}
```
Овал сам увеличивается под количество проектов, картины распределяются по кругу равномерно и чередуются по стенам.
Если оставить `images: []`, нарисуется заглушка.

**Важно про фото.** Браузеры запрещают 3D-сцене (WebGL) читать картинки, открытые через `file://`.
Поэтому настоящие фото появятся на стенах, когда сайт открыт с сервера (GitHub Pages или любой хостинг).
При открытии двойным кликом на стене будет заглушка, а в панели проекта всё равно видны настоящие фото.

## Тексты и языки
Все тексты лежат в `i18n.js`, включая надписи на стенах (вход, финальная стена, таблички).
Год основания, телефон, номер WhatsApp и версия задаются в `NXT_SITE` в начале файла.
Новый язык: добавь блок в `NXT_I18N`, кнопку в `.lang` в HTML и код в массив `LANGS` в `script.js`.

## Логотип
Замени `assets/logo/nxt-logo-black.svg` и `nxt-logo-white.svg` своими файлами.
Логотип на стене при входе рисуется кодом (функция `drawLogo` в `script.js`). Его можно заменить на картинку.

## Управление
- Колесо мыши или свайп вверх-вниз: идти вперёд и назад, с инерцией.
- Наведение мыши: курсор-рука, картина чуть приподнимается, свет над ней теплеет. Лёгкий параллакс от движения мыши.
- Клик или тап по картине: подлёт и панель проекта.
- Назад: кнопка «Назад в галерею», Esc, скролл или клик мимо картины.
- Конца нет: после последней картины снова вход и первая картина.
- Подвал с контактами открывается кнопкой «Контакты» в шапке и закрывается скроллом, Esc или той же кнопкой.

## Форма коридора
Кольцо в форме стадиона: две длинные прямые галереи (видны обе стены) и два плавных разворота.
На разворотах камера смещается к внешней стене и смотрит внутрь, чтобы были видны картины на обеих стенах.
Радиус разворота задаётся `R_TURN` в `script.js`, длина прямых считается сама по количеству проектов.

## Качество графики («ультра»)
- На компьютерах сцена рендерится с запасом по разрешению (минимум 1,5x), со сглаживанием и чёткой фильтрацией текстур.
- Фото, надписи на стенах и таблички рисуются в повышенном разрешении.
- Мягкие тени в углах у пола и потолка, белое паспарту внутри рам.

## Производительность
- Свет «запечён» в текстуры, реальные источники только для бронзовых рам.
- Отражения в полу отключаются на телефонах и слабых компьютерах. Если в первые секунды меньше 48 fps, качество снижается автоматически.
- Фото подгружаются по мере приближения и выгружаются позади.
- Кадр перерисовывается только когда что-то изменилось.

## GitHub Pages
1. Залей содержимое папки в репозиторий.
2. Settings → Pages → Deploy from a branch → ветка, папка `/ (root)` (или `/museum`, если лежит в подпапке).
3. Сайт будет на `https://<user>.github.io/<repo>/`.
