# Venezia Showroom: 3D-прогулка

Чистые HTML + CSS + JS (three.js r160, ES-модули), без сборки. Из-за модулей открывать через сервер: GitHub Pages или локально `python3 -m http.server` в этой папке (двойной клик по файлу не сработает).

## Что умеет
- Модель двух этажей шоурума (299 м²) по планировке и визуализациям: ресепшн с оливой, Living Zone 1 с круглым диваном и жемчужными гирляндами, Living Zone 2, рабочий стол, кухня с островом, лестница; на втором этаже спальня, ванная с чёрной ванной, презентационный остров из красного мрамора, переговорка и офис.
- Движение только по заданному маршруту, как в Street View: тяни, чтобы осмотреться; жми стрелку на полу, кружок-точку, просто тапни в сторону, куда хочешь идти, или точку на мини-карте.
- Кнопки ← / → и точки внизу, автотур (▶), колесо/щипок для зума, клавиши ← → ↑ ↓.

## Графика
- Тени от солнца через окна, ambient occlusion (GTAO) и свечение (bloom) в кадре, когда камера стоит. Во время движения работает облегчённый проход с адаптивным разрешением, чтобы держать частоту экрана (60/90/120 Гц).
- Мрамор, плетёная кожа, бронзовая сетка, рифлёный травертин и замша вырезаны из инспирейшн-досок проекта (`assets/tex`). Дерево, травертин пола, штукатурка и букле генерируются кодом.
- На точках с кнопкой «Render» открывается настоящая визуализация этого вида (`assets/renders`).
- Чувствительность пальца/мыши: `LOOK_SENS` в `showroom.js`.

## Как поменять маршрут
В `showroom.js` найди массив `NODES`: каждая точка `{ x, z, f, yaw, name }`.
`x` 0..26 м слева направо по плану, `z` 0..9 м от задней стены к фасаду, `f` этаж (0 или 1), `yaw` куда смотреть при остановке (0 на заднюю стену, 90 вправо, −90 влево, 180 на окна).
Порядок в массиве = порядок маршрута.

## Структура
```
index.html      разметка, HUD, мини-карта, просмотр рендера
style.css       стили
showroom.js     сцена (стены, мебель, свет), маршрут, управление, рендер
vendor/         three.js r160 + нужные аддоны (локально, без CDN)
assets/tex      фото-текстуры с инспирейшн-досок
assets/renders  визуализации для кнопки «Render"
```
