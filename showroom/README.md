# Venezia Showroom: 3D-прогулка

Чистые HTML + CSS + JS (three.js r128), без сборки. Открой `index.html` (лучше через любой локальный сервер или GitHub Pages).

## Что умеет
- Модель двух этажей шоурума (299 м²) по планировке и визуализациям: ресепшн с оливой, Living Zone 1 с круглым диваном и жемчужными гирляндами, Living Zone 2, рабочий стол, кухня с островом, лестница; на втором этаже спальня, ванная с чёрной ванной, презентационный остров из красного мрамора, переговорка и офис.
- Движение только по заданному маршруту, как в Street View: тяни, чтобы осмотреться; жми стрелку на полу, кружок-точку, просто тапни в сторону, куда хочешь идти, или точку на мини-карте.
- Кнопки ← / → и точки внизу, автотур (▶), колесо/щипок для зума, клавиши ← → ↑ ↓.

## Как поменять маршрут
В `showroom.js` найди массив `NODES`: каждая точка `{ x, z, f, yaw, name }`.
`x` 0..26 м слева направо по плану, `z` 0..9 м от задней стены к фасаду, `f` этаж (0 или 1), `yaw` куда смотреть при остановке (0 на заднюю стену, 90 вправо, −90 влево, 180 на окна).
Порядок в массиве = порядок маршрута.

## Структура
```
index.html   разметка, HUD, мини-карта
style.css    стили
showroom.js  сцена (стены, мебель, свет), маршрут, управление
vendor/      three.min.js на случай, если CDN недоступен
```
