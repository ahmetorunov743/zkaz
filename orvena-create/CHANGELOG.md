# Changelog

## 0.0.2 — 2D games (2026-11-26)

- Game stage brick: sprites with costumes, layers, clones, speech bubbles.
- Physics: gravity, falling bodies and static supports, bounce, friction, collisions, solid edges.
- Pictures: draw your own, pick ready-made emoji and shapes, or import a photo. New «Картинка» brick.
- Block compartments with colors and a search line: events, control, motion, looks, physics, sound,
  interface, sensing, operators, variables and lists.
- Scripts run in parallel like in Scratch: wait, forever, repeat until, wait until, stop.
- Broadcasts: «отправить всем» starts every «когда я получу» script in the chain; «и ждать» waits for them.
- Text input: «спросить и ждать» + «ответ». Sensors: finger, tilt, timer, date and time.
- Sound notes and vibration. Every sprite and the screen have their own scripts.
- New sample game «Прыгай!».

## 0.0.1 — demo (2026-11-26)

First demo of Orvena Create.

- Brick designer with live preview: column, row, card, text, button, input, checkbox, divider, spacer.
- Logic blocks: events, properties, variables, messages, screens, if/else, repeat; nested value blocks.
- Multiple screens, in-editor run.
- On-device APK export: manifest patching, project packaging, v2/v3 signing, install and share.
- Sample project «Счётчик».
