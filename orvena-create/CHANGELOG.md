# Changelog

## 0.0.1 — demo (2026-11-26)

First demo of Orvena Create.

- Brick designer with live preview: column, row, card, text, button, input, checkbox, divider, spacer.
- Logic blocks: events, properties, variables, messages, screens, if/else, repeat; nested value blocks.
- Multiple screens, in-editor run.
- On-device APK export: manifest patching, project packaging, v2/v3 signing, install and share.
- Sample project «Счётчик».
